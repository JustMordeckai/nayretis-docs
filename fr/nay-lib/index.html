nay_lib ​

nay_lib est la bibliothèque commune de tous les scripts Nayretis. Vous la recevez avec chaque achat, vous l'installez une fois, et chaque script Nayretis que vous ajoutez l'utilise.

Ce qu'elle apporte ​

  • Un seul panneau de réglages, /nay, pour tous les scripts Nayretis. Les réglages sont enregistrés dans votre base et appliqués à tous les joueurs dès l'enregistrement. Voir Panneau /nay.
  • Des permissions par ACE ou par identifiant Discord, Steam, FiveM ou license. Voir Permissions.
  • Six langues : anglais, français, espagnol, portugais, polonais et allemand. Une traduction manquante retombe sur l'anglais.
  • Un bridge de frameworks : ESX Legacy, QBCore, QBox et ox_core détectés automatiquement, avec leurs inventaires, targets et notifications. Voir Bridge.
  • Une API HTTP pour votre site, votre tableau de bord ou votre bot Discord, désactivée par défaut. Voir API HTTP.
  • Des webhooks, messages Discord compris, pour les événements des scripts. Voir Webhooks.
  • Un journal de chaque changement fait en jeu, depuis la console ou par l'API. Voir Journal.
  • Les notifications, invites de touche et barres de progression Nayretis, partagées par tous les scripts.

Prérequis et ordre de démarrage ​

La seule dépendance est oxmysql. Démarrez nay_lib après votre framework, votre inventaire et votre target, et avant tous les scripts Nayretis :

cfg
ensure oxmysql
ensure nay_lib

Les tables sont créées au premier démarrage. Les options qui se règlent dans server.cfg sont sur la page Convars.
