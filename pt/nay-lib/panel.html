Painel /nay ​

Escreva /nay no jogo para abrir o painel de definições. Vê todos os scripts Nayretis que tem permissão para configurar. Os jogadores com nay.admin veem também a secção Servidor: a página Nayretis, Permissões, API, Webhooks e Registo.

As definições são guardadas na base de dados. Quando clica em Guardar, o novo valor é verificado, armazenado, gravado no registo e aplicado de imediato a todos os jogadores ligados. Não é preciso reiniciar.

Algumas páginas de scripts têm também botões de ação, como Gerir túneis na página Car Wash.

Definições Nayretis ​

A página Nayretis reúne as definições partilhadas por todos os scripts.

A coluna No /nay mostra o nome apresentado no painel. A chave é o nome usado pelo config.lua e pela API HTTP.

Quem pode abrir o painel ​

  • nay.admin dá acesso a tudo.
  • nay.config dá acesso às definições de todos os scripts.
  • nay.audit abre o painel no registo.
  • <resource>.config dá acesso às definições de um script, por exemplo nay_car_wash.config.
