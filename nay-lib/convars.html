Convars ​

Most settings are edited in game with /nay. A few options live in server.cfg because they are needed before the database is read, or because they concern the server itself.

cfg
setr nay:framework "auto"
setr nay:inventory "auto"
setr nay:target "auto"
setr nay:notify "auto"
setr nay:locale "en"
set nay:logLevel "info"
set nay:versionCheck "true"
set nay:apiTrustedProxies ""
setr nay:debugZones "false"

Use setr where the table says so: the client reads those values too.

ConvarSet withDefaultDescription
nay:frameworksetrautoForces the framework adapter: esx, qbcore, qbox, ox, custom. See Bridge.
nay:inventorysetrautoForces the inventory adapter: ox_inventory, qs-inventory, qb-inventory, framework.
nay:targetsetrautoForces the target adapter: ox_target, qb-target, none.
nay:notifysetrautoForces the notifications: ox_lib, nayretis, framework, native.
nay:localesetrenLanguage used until it is changed in /nay: en, fr, es, pt, pl, de.
nay:logLevelsetinfoConsole log level: debug, info, warn, error.
nay:versionChecksettrueReads the public version file at start and prints available updates. false turns it off.
nay:versionUrlsetNayretis version fileAdvanced: another version file URL. Leave it unset.
nay:apiTrustedProxiessetemptyReverse proxies whose X-Forwarded-For is trusted, as comma separated addresses or CIDR ranges. See HTTPS.
nay:debugZonessetrfalsetrue draws every zone outline in game. For setup only.
