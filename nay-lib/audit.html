Audit log ​

The Audit log tab of /nay lists every change made to your Nayretis scripts:

  • settings, with their old and new values;
  • permission rules;
  • API tokens;
  • webhooks;
  • API calls that change something (api.call, actor api:<token label>).

Filter by resource, action, actor and dates. The same rows are available through the API route /nay_lib/v1/audit (see HTTP API).

Access ​

The tab needs the scope nay.audit, included in nay.admin. See Permissions.

Retention ​

Audit log retention (days) (AuditRetentionDays) on the Nayretis page of /nay deletes older rows every day. The default is 90 days. 0 keeps everything.
