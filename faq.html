FAQ ​

The console says You lack the required entitlement ​

The script is not linked to the Cfx.re account that owns your server license key. Check in Portal that the account which bought the script is the one that created the key in sv_licenseKey. Entitlements are read when the server starts: restart the whole server after a new purchase, a restart of the resource is not enough.

nay_car_wash says nay_lib is not started ​

nay_lib must start before every Nayretis script. Check the order of the ensure lines in server.cfg: ensure nay_lib comes first, after your framework, inventory and target resources.

My framework is not detected ​

Start nay_lib after your framework resource. If detection still fails, force it in server.cfg, for example setr nay:framework "esx". The values are listed on the Bridge page. Running a framework that is not supported? Write a custom adapter.

Database errors on start ​

oxmysql must be started before nay_lib and connected to your database (mysql_connection_string in server.cfg). The tables are created on the first start, so the database user needs the right to create tables.

How do I change the language? ​

Open /nay, then Nayretis, then Language. English, French, Spanish, Portuguese, Polish and German are included, and the language applies to every Nayretis script. setr nay:locale "fr" in server.cfg sets the language used before anyone changes it in game.

Which files can I edit? ​

  • config.lua of each script: optional starting values. Once the server has started, settings live in the database and are edited with /nay.
  • locales/*.json: every text shown to players.
  • nay_lib/bridge/custom.lua: your own framework adapter.

The rest of the code is protected by Cfx escrow.

Does nay_lib connect to anything? ​

At start, nay_lib reads a public version file (https://versions.nayretis.com/versions.json) and prints in the console when an update is available. Turn it off with set nay:versionCheck false. Nothing else leaves your server unless you turn on the HTTP API or add webhooks.

Where do I get help? ​

Open a post in #support on the Nayretis Discord, one post per issue, with the script and its version, your framework, inventory and target, and the server console and F8 errors.
